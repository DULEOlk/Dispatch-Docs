# 阶段交接模板

新阶段复制为 `handoffs/YYYY-MM-DD-主题.md`；同阶段续做更新原文件，不为每次微调另开文档。填实值；没有完成就写未完成，不保留空的成功声明。始终保留子任务/父级编号、授权边界、实际结果与证据、停止点和下一步；其余没有发生或不适用的字段可合并为“不适用”，不逐项堆空栏。稳定范围可链接原设计，命令/结果只记录一次；保留有价值的失败与方案替代历史。

## 身份与范围

- 日期/时区：
- 用户本次目标与最新修正：
- 已授权范围 / 仍待确认范围：
- 项目绝对路径、分支、HEAD：
- 当前阶段及具体小任务：
- 子任务 ID：
- 覆盖的父级 `DEMO-*` 编号：
- 明确不覆盖的相邻总设计项：
- 开工条件及是否满足：
- 退出条件和用户可观察成果：

## 确认依据与需求覆盖

- 当前有效设计段落链接（含字段含义/选项/行为；不得只写“原字段”）：
- 用户确认来源（对话标题/ID、必要回合ID；已读范围，或无法核对的缺口）：
- 当前参考图及本轮实际打开的图（日期/版本、用途、有效区域、被替代部分；不是永久定稿）：
- 本次迭代对象、原因、旧→新变化与保留部分；上次验收版本（缺证据写未建立）、当前工作区实际情况、候选/已确认待实现目标（稳定内容用链接）：
- 是否已满足该模块/子范围退出条件；实施、验证及所需人工验收证据；是否可替换实际版本，若不可写明剩余项：
- 涉及旧内容的核对范围与待核对疑点；受影响的文本、图片、实现及验收项：
- 助手建议/推测与用户明确确认的区别；替代/否决的方案及其原位置标记：
- 按本轮实际需求列最小覆盖表，不堆空项：

| 用户要求 | 当前代码/资产入口 | 本轮证据与输入/配置 | 未覆盖/未实现/待人工 |
|---|---|---|---|
| 填实值 | 填实值 | 静态/编译/读取/渲染分别说明 | 填实值 |

## 工作区

- 开始时已有的修改/未跟踪文件：
- 本轮实际修改的文件和作用：
- 用户资产、其他任务改动及保护说明：
- 是否提交/推送，若有列 commit：

## 完成与验证

- 已实现行为（与设计目标分开）：
- 本轮四类状态变化（设计 / 代码 / 自动验证 / 人工验收）：
- 因本轮修改被标记“需要重验”的既有矩阵项：
- 实际执行命令、构建配置、测试过滤器：
- 通过/失败/未运行数、退出状态：
- 日志/证据路径、日期、版本对应依据（HEAD与相关脏改快照/哈希、资产/输入及实际加载配置）；必要证据的稳定留存位置：
- 人工验证结果或未验证事项：

## 未完成与风险

- 问题编号、触发条件、源码路径/函数/行号：
- 是实际复现、静态追踪还是待确认推测：
- 已尝试步骤及结果，避免下次重复：
- 当前运行中的工具/进程/代理及日志，或明确“全部结束”：

## 下一步

- 下一个最小动作及验收方式：
- 依赖条件与是否需要用户输入：
- 需修改的蓝图/资产（尚未执行）：
- 本轮决策及原因，链接 DECISIONS：
- CURRENT 停止点：已更新 / 核对无变化。
- 已纠正的原位置/替代链接；旧测试是否仅证明被否决方案；是否已重编译/加载撤回后的源码：
- 恢复检查：下一位能定位当前实际版本、待实现目标、各自图文依据、实现差距和第一个动作，且不用重读全部对话：
- IMPLEMENTATION_MATRIX：已更新哪些子任务/`DEMO-*` 行 / 核对无变化（不因写了交接就重复改行）。
- 当前主要进行中子任务 / 等待队列是否已同步：

旧 STATUS 是只读历史入口，不再要求同步追加。
